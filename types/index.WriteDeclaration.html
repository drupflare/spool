    Type Alias WriteDeclaration

    The declaration defineWrite takes. Every write class is "the last value wins" for one key per principal, applied only when the version the device edited from is still current. There is no class for a comment, a cart, a payment, a counter, an inventory change or an audit record, and kind accepts nothing but last-value.
