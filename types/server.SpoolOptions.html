    Optionalcdn

    cdn?: { integrity: string; url?: string; worker?: boolean | { url: string } }

    serve the page runtime from a CDN with SRI; omitted, it is served from /.spool/<version>/client.js. url defaults to this version's cdn.drupflare.com build, whose integrity is in the release notes and in dist/cdn/manifest.json.

    worker also moves the worker core to the CDN: the stub becomes the config and one importScripts line, a few KB in place of the core, and the core is fetched from worker.url, or from this version's cdn.drupflare.com build when worker is true. A browser has no integrity check for an imported script, so the site trusts the CDN host with a script that can answer every request of the origin. Off by default. A site with a custom worker bundle must give worker.url. publishStatic checks the served bytes with verifyCore.

    OptionalclientTag

    clientTag?: "inline" | "script"

    How a second-view page loads the runtime. inline (default) puts a small gate in place of the script tag. The gate waits for the first click or GET form submit that the held pages answer, then loads one script that carries the runtime and the pack, in place of the document that click would have fetched, so a visitor never makes more requests than the site without spool. A page with no ring, or whose ring names no boot script (cdn is set), loads the runtime from the second view. script keeps the tag, for a page whose CSP forbids inline scripts. A first-view site always uses the tag.

    Optionalfreshness

    freshness?: { maxAge?: number }

    maxAge, in seconds, is the lease of /spool-sw.js in the browser's cache; default one day. A check inside it costs nothing, and after it one request brings the version and its changes. A floor applies on top of the lease: Chromium checked the stub on the first document navigation after each 24 hours whatever maxAge was (measured in Chromium only, with the wall clock shifted), so a lease longer than a day does not cut the checks. A stub that changed at that check installs, which is the contact.

    OptionalinlineMaxBytes

    inlineMaxBytes?: number

    The most bytes of escaped artifact JSON a public template page carries in the page itself, so the worker stores it from the navigation and asks no /.spool/artifact. Every network view of such a page pays for the bytes and one more load, whether or not the visitor has a worker; a larger artifact is left out. Default 0, which is off; 2048 is the limit measured.

    Optionallive

    live?: boolean | "always" | LiveOptions

    The stream a visible page holds open at /.spool/live, for the principal lease and its revocation and, with public, for pushed tag changes. A page with a principal partition and a stream sends no renewal while it reads, and a revoked session reaches it in milliseconds. false is off; true and an object are on; absent, it is on when identity is set on a host that is one process (Node, Bun, Deno) and off on Workers, where the stream needs a hub every isolate can reach: pass durableObjectHub from @drupflare/spool/stores/durable-object. A page without the stream renews at its route's bound as before. The default is off for public freshness. By default the policy is adaptive: the first lease renewal of a visible session is an ordinary request and the second becomes the stream, so a visitor who loads documents never opens one. 'always' (or { mode: 'always' }) opens at login and whenever a tab becomes visible, for an app that stays open.
