    OptionalinlineMaxBytes

    inlineMaxBytes?: number

    The most bytes of escaped artifact JSON a public template page carries in the page itself, so the worker stores it from the navigation and asks no /.spool/artifact. Every network view of such a page pays for the bytes and one more load, whether or not the visitor has a worker; a larger artifact is left out. Default 0, which is off; 2048 is the limit measured.
