    Optionallive

    live?: { mode: "adaptive" | "always"; public: boolean; socket?: true }

    Present while the server answers /.spool/live. public is true when the stream also carries public freshness, so the worker treats its public replica as current while a lease is open. mode is always when the page opens the stream whenever it is visible, and adaptive when the worker asks for it at the second lease renewal of a page's visible session. socket is true when the hub also accepts a WebSocket upgrade at the same path; a page then opens a socket and falls back to server-sent events if the upgrade fails.
