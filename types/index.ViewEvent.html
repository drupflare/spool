    crossOriginLoads

    crossOriginLoads: number | null

    Cross-origin resources the page loaded during the view, as the page runtime counted them from PerformanceResourceTiming when it was hidden. Without Timing-Allow-Origin such an entry has a transfer size of 0 whether it came from cache or network, so a cache hit counts: this is an upper bound on cross-origin network requests. Null until the page reports, and when it never does.
