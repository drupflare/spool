    Function analyticsEngineSink

    • analyticsEngineSink(dataset: AnalyticsEngineLike): Sink

      A sink for a Workers Analytics Engine dataset, one data point per event.

      views other requests
      index1 route pattern path
      blob1 view beacon
      blob2 to blob9 tier, reason, engine, scope, strategy, route, id, from content type, body slice, vendor
      double1 to double6 at, staleSec, swAgeMs, gapMs, mismatch, crossOriginLoads at, slice number from 0, slice count

      staleSec, gapMs and crossOriginLoads are -1 when unknown; mismatch is -1 when nothing was compared, 0 for a match and 1 for a mismatch. A page's loads report is a row with blob1 of loads, the view id as blob2 and at and the count as double1 and double2. Analytics Engine caps an index at 96 bytes and a row at 16 KB, so a body longer than MAX_BEACON_BLOB bytes is written as several points, one per slice, with the same index, content type, vendor and at; join the slices by those and double2 (the slice number) to rebuild it. Nothing is cut off.
